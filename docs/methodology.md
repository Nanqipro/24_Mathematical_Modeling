# 建模方法与证据边界

## 研究问题

项目围绕一段约 5 km、含两条行车道和一条应急车道的高速公路展开，目标是：

1. 从四个视频监测点统计流量、密度和速度，构建可提前约 10 分钟预警持续拥堵的模型；
2. 建立应急车道临时启用的定量依据；
3. 设计实时启用规则并评估启用前后的改善；
4. 在成本约束下优化视频监控点布置。

## 处理链路

### 1. 视频感知

公开代码中的跟踪器组合 YOLOv5 与 Deep SORT：

- YOLOv5 对车辆进行逐帧检测；
- Deep SORT 维护跨帧轨迹 ID；
- 两条水平区域线用于判断车辆进入、离开和车道位置；
- 跟踪结果可输出视频、文本、CSV，数据库上传为可选功能。

论文正文描述的是 YOLOv8 检测流程，但仓库实现是 YOLOv5。由于没有保留同一版本的完整训练与推理记录，公开整理版明确将两者视为不同实验实现。

### 2. 交通状态

从固定时间间隔内的车辆计数推导基础状态：

\[
q = \frac{N}{\Delta t}\times 3600
\]

\[
\rho = \frac{N}{L}\times 1000
\]

\[
v = \frac{q}{\rho}
\]

其中 \(N\) 为区间车辆数，\(\Delta t\) 为秒级统计间隔，\(L\) 为米级观测道路长度，\(q\)、\(\rho\)、\(v\) 分别对应每小时流量、每公里密度与 km/h 速度。竞赛期不同脚本对单位和缩放因子存在差异，二次研究时应先统一口径。

派生数据进一步包含加权流量、加权速度、拥堵系数、平滑拥堵系数、动态容量、TPI 与阻塞概率。

### 3. 拥堵预测

仓库保留三组阻塞系数预测结果：

- Gradient Boosting
- Random Forest
- XGBoost

`scripts/evaluate_predictions.py` 对“实际值”和“预测值”同时非空的 4,351 行计算 MAE、RMSE 和 \(R^2\)。结果反映存储文件内部的一致性，不构成独立测试集上的泛化证明。

### 4. 应急车道启用决策

论文方法综合：

- 实际流量与动态通行能力；
- 天气、事故等外部影响；
- 交通流中断概率；
- Z-score 标准化；
- 熵权法客观权重；
- 专家权重调整；
- 改进 TOPSIS 的理想解与反理想解距离。

最终相对接近度用于量化候选方案与理想状态的距离，辅助判断是否临时启用应急车道。

### 5. 监控点布局

论文提出利用 LSTM 时序预测评估监测点位置和数量，并结合覆盖范围、数据采集频率与设备成本优化布局。当前仓库未保留这部分的完整训练代码和可执行优化程序，因此只作为论文层方法记录。

## 原始假设

- 视频数据能够代表真实交通状态，暂不考虑丢帧与检测误差；
- 统计时间间隔内交通流近似平稳；
- 简化观测点之间的相互影响；
- 简化车辆换道行为。

这些假设方便建模，但对真实部署过强。后续研究应加入检测误差传播、上下游耦合、事故与天气数据、换道行为以及不同道路几何条件。

## 复核建议

1. 补齐原始视频到车辆计数的可追溯清单；
2. 固定训练/验证/测试划分与随机种子；
3. 把单位、窗口长度、平滑系数和阈值集中到显式配置；
4. 使用滚动时间窗交叉验证，避免时间泄漏；
5. 报告基线模型、置信区间和拥堵类别不平衡；
6. 用仿真或受控试验验证应急车道决策，而不是只依赖离线评分。
